Phase 02 — HUD Refinement & Alignment

  • **Objective:** Refine the BCO HUD layout for alignment, spacing, and readability; remove overlapping elements and standardize control sizing.
  • **Status:** Planning.
  • **Scope:** In: HUD layout adjustments, control alignment, spacing and padding, typographic contrast for labels/help, consistent control sizing; Out: new features or engine changes.
  • **Definition of completion:** HUD renders without overlap, with consistent padding/gaps, aligned labels/readouts, and 44px+ hit targets; updated stage action and validation notes.
  • **Stages:**
  • HUD polish stage -> AI_first/projects/ui_redesign/phases/phase02/actions/ui_redesign_phase02_stage_hud_polish_action.md
  • **Dependencies:** Phase 01 Discovery & Direction complete.
  • **Risks/assumptions:** Pygame panel remains fixed-width; ensure changes don’t regress performance or readability at small heights.
